## Critical Patterns

### K8s Resource Naming
- Pod: `dep-{deploymentId}-{replicaset}-{random}` in namespace `jarble`
- Secret: `secret-{deploymentId}`
- PVC: `pvc-{deploymentId}` (Longhorn, 20Gi RWO)

### Config Paths on Pod
- `/data/config/openclaw.json` — Written by configSync (Jarble platform)
- `/data/.openclaw/openclaw.json` — Generated by OpenClaw entrypoint (native config)
- OpenClaw reads Telegram/Discord tokens from **K8s Secret env vars**, NOT from openclaw.json
- configSync writes to `/data/config/` but OpenClaw reads its own from `/data/.openclaw/`

### ConfigSync Pipeline
DB → buildDeploymentFields → renderConfigs + getSecretEntries → writeConfigsToPvc → updateDeploymentSecret → restartDeployment → pollForReadiness

### SQLite Dev DB
- File-based at `jarble-api-main/local.db` (changed from `:memory:` to persist across tsx watch restarts)
- Seed data created on every startup in `db/init.ts`

### Claude Max OAuth Tokens
- `sk-ant-oat*` tokens can't be validated via Anthropic API — auto-passed by prefix in `openrouter.ts:validateProviderKey`
- Use Bearer auth (not x-api-key) for these tokens

### npm Cache Corruption on PVC
- Recurring issue: `ENOTEMPTY` errors during `npx openclaw` on shared PVC
- Fix: `rm -rf /data/.npm /data/runtime/node_modules /data/.initialized` then delete pod
- Root cause: concurrent npm operations on Longhorn PVC

### Deployment Status "creating" Stuck
- Deployment creation sets status to "creating" but polling for "running" often times out
- Workaround: debug endpoint `POST /debug/deployment/:id/status` to manually set status

## Infrastructure Roadmap (from OpenClaw bot audit)
See CLAUDE.md "Infrastructure Roadmap" section. Key priorities:
1. Liveness/readiness probes on port 18789 (OpenClaw hangs go undetected)
2. Pod Security Standards (restricted profile at namespace level)
3. Pre-built image (eliminates 2-3 min npm install + cache corruption)
4. Idle pod shutdown (scale to 0 after 24h inactivity)
5. LLM spend limits per user
6. ConfigSync atomicity (partial failures leave inconsistent state)
