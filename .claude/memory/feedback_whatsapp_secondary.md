WhatsApp QR pairing, Discord, Slack, Telegram connections are optional "connect your own" extras — not the primary path. The web chat (`/d/[id]`) is the main interface now. Prioritize web chat bugs over messaging platform bugs.

**Why:** The platform evolved from bot-deployment-to-messaging to web-first chat with optional messaging integrations.
**How to apply:** When triaging bugs, web chat path issues are higher priority than WhatsApp/Discord/Slack/Telegram issues. QR stream and messaging platform bugs are real but lower priority.
