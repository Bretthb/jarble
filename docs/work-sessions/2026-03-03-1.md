### 2. Composio Integration Research
Investigated whether Composio (composio.dev) could help accelerate Jarble development.

- Launched 3 parallel research agents (platform overview, MCP integration, bot platform fit)

- Saved research to `research/composio-integration/composio-research.md`

### 3. Fixed Auth0 JWT Verification Failure
User was getting `TRPCClientError: You must be logged in` on every request after login.

- Initial symptom: `JWKSTimeout: request timed out` on every JWT verification
- Investigated: Node.js `fetch` to JWKS URL worked standalone, but failed inside running API server
- **Root cause**: `jarble-api-main/.env` file was missing entirely. `AUTH0_DOMAIN` defaulted to `"test.auth0.com"` (from `env.ts` line 14) instead of `"jarble-dev.us.auth0.com"`. The server was verifying JWTs against the wrong JWKS endpoint.
- **Fix**: Created `jarble-api-main/.env` with correct `AUTH0_DOMAIN=jarble-dev.us.auth0.com` and `AUTH0_AUDIENCE=https://api.jarble.ai`
- Restarted API server, verified auth works — dashboard loads with deployment data

### 4. Fixed ChunkLoadError
Frontend had stale `.next` cache causing `ChunkLoadError: Loading chunk app/layout failed (timeout)`.
- Fix: Killed frontend, `rm -rf .next`, restarted.

### 5. Fixed `packages.list` tRPC 404
Frontend was calling `packages.list` but getting "No procedure found on path".
- **Root cause**: `packagesRouter` was imported in `trpc/index.ts` but never registered in `appRouter`
- **Fix**: Added `packages: packagesRouter` to the `appRouter` object

### 6. Fixed Component Gallery 500 (MCP server missing from pod)
Opening the "Library" panel on the chat page triggered a 500 error.
- **Root cause**: `/data/config/mcp/jarble-ui-server.js` didn't exist on the pod — configSync had previously failed
- **Fix**: Triggered configSync via debug endpoint, which deployed the 65KB MCP server script to the pod
- Component Gallery now works (can list/load/delete saved components)
