### 2. Chart Height Collapse Bug Fix

**File**: `Jarble-mvp/components/canvas/components/CanvasChart.tsx`
**Severity**: High — all chart types rendered at 0px height

**Root Cause**: Recharts `ResponsiveContainer` (used inside shadcn's `ChartContainer`) needs a parent with resolved pixel height. The CSS flex chain (`h-full` + `flex-1` + `min-h-0`) collapsed to 0px in the grid layout because grid cells grow to content size, not the other way around.

**Fix**: Removed the flex wrapper. Applied `style={{ height: chartHeight }}` directly on `ChartContainer` with `className="aspect-auto w-full"`. Default height is 250px, overridable via `height` prop. All 4 chart types (bar, line, area, pie) now render correctly.

```tsx
// Line 240-254 of CanvasChart.tsx
const chartHeight = height || 250;
return (
  <motion.div ...>
    {title && <h3 ...>{title}</h3>}
    <ChartContainer config={chartConfig} className="aspect-auto w-full" style={{ height: chartHeight }}>
      {renderChart()!}
    </ChartContainer>
  </motion.div>
);
```

## Key Findings During Testing

### Prop Format Gotchas (Important for future reference)
| Component | Gotcha | Correct Format |
|-----------|--------|----------------|
| chart | NOT `data`/`xKey`/`yKeys` | `dataKeys: string[]`, `xAxisKey: string`, `data: Record[]` |
| stat_grid | Stats array shape | `stats: { label, value, change?, trend? }[]` |
| progress | Value is 0-100 | `value: number`, `label: string`, `showPercentage: boolean` |
| form | Fields array | `fields: { name, label, type, placeholder?, required?, options? }[]` |
| steps | Current is 0-indexed | `current: number`, `items: { title, description }[]` |
| descriptions | Items array | `items: { label, value }[]`, `columns?: number` |
| carousel | Items with image | `items: { title, description, image }[]` |
| sandbox | HTML + JS separate | `html: string`, `js?: string`, `css?: string` |
